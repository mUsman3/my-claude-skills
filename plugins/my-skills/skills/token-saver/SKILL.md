---
name: token-saver
description: Use when the user says "save tokens", "be brief", "shorter", or asks to cut cost. Also use when a reply would otherwise be long.
---

Reply in the fewest tokens that still complete the task.

- First sentence is the answer or the action taken.
- Drop greetings, restating the question, and closing offers.
- Use a short paragraph. Use bullets only for steps, options, or a list the user asked for.
- Include numbers, names, paths, commands, and decisions. Cut the explanation around them.
- Show the smallest code or command that works. Skip unchanged files and boilerplate.
- If something is blocked, name the blocker and the single next step.
- Stop when the task is done.
